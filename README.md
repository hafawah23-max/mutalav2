# مُطَلعٌ | رفيق القراءة

تطبيق Flutter عربي يعمل دون إنترنت، لقراءة ملفات PDF الموجودة على الهاتف، وإنشاء خطط قراءة يومية، وحفظ الإنجاز، وتذكيرات محلية.

## تشغيله من GitHub دون تثبيت Flutter

1. أنشئ مستودع GitHub جديدًا، مثل `mutala`.
2. ارفع **محتويات** هذا المجلد إلى جذر المستودع، بما فيها مجلد `.github` المخفي.
3. افتح تبويب **Actions** ثم اختر **Build Android APK** واضغط **Run workflow**. سيعمل البناء أيضًا تلقائيًا عند الدفع إلى `main`.
4. عند اكتمال البناء افتح نتيجة العملية، ثم **Artifacts** وحمّل `mutala-android-apk`.
5. فك ضغط الملف وحمّل `app-release.apk` إلى هاتف أندرويد وثبّته (قد تحتاج إلى السماح بتثبيت التطبيقات من هذا المصدر).

> ملف APK الناتج تجريبي وموقّع بمفتاح التطوير الافتراضي الخاص ببناء Flutter، وليس إعداد نشر على Google Play. قبل النشر يلزم توقيع إصدار خاص، واسم حزمة فريد، واختبار شامل.

## التشغيل محليًا

```bash
flutter create --platforms=android --project-name mutala .
flutter pub get
flutter run
```

لبناء APK محليًا يجب إضافة أذونات Android ومستقبلات الإشعارات كما في workflow، ثم تشغيل `flutter build apk --release`.

## ما الذي تنفذه هذه النسخة؟

- واجهة عربية، مكتبة محلية، إحصاءات بسيطة.
- اختيار PDF من ملفات الجهاز ونسخه إلى مساحة التطبيق.
- عرض PDF داخل التطبيق، والاحتفاظ بأعلى صفحة وصل إليها المستخدم.
- تحديد مدة خطة القراءة وموعد التذكير اليومي.
- حساب عدد الصفحات اليومي بعد اكتشاف عدد صفحات PDF عند فتحه أول مرة.
- إشعارات محلية يومية وتوقفها عند اكتمال الكتاب.
- حذف الكتاب أو تعديل الخطة.

## حدود النسخة الأولية

- **لم يتم التحقق من بناء APK فعليًا في هذه البيئة**؛ يجب تشغيل GitHub Actions ومراجعة أي أخطاء توافق في الاعتماديات.
- تسجيل الإنجاز يعتمد على أعلى صفحة زارها المستخدم، وليس التحقق من قراءة كل صفحة.
- الإشعارات المحلية غير الدقيقة قد تتأخر بحسب إعدادات توفير الطاقة على بعض الهواتف.
- لا تتضمن مزامنة سحابية أو قارئ EPUB أو ملاحظات أو أوسمة متقدمة بعد.
- حذف بيانات التطبيق أو إلغاء تثبيته يحذف المكتبة المحلية؛ ينصح بإضافة تصدير/استيراد نسخ احتياطية قبل الاعتماد عليه طويلًا.
- ملفات PDF المحمية أو غير المتوافقة قد لا تفتح.

## خصوصية

الكتب وخطط القراءة تبقى محليًا على الجهاز، ولا يتطلب التطبيق خادمًا أو حساب مستخدم.
